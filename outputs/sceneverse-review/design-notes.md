## Direction

Replace the oversized headset/Neo/pills metaphor with a paused cinema portal opening onto a layered original corridor. Character cards show generated agents, the microphone represents Vera, the director chair represents meta-level questions. The optional visor is set aside. Four short captions explain pause, scene analysis, character conversation and Director context. The 3D scene uses actual geometry and keeps the existing drag, pause and reduced-motion controls.

The image tool rejected an initial franchise-based concept. The selected artwork uses entirely original Maya/Riven characters from the local prototype. Generated with the built-in image tool. One cinematic artwork is intentionally used for both themes.

Artwork: `public/landing/assets/projects/067-sceneverse-cinema-v4.png`.

## Seated interaction correction

The viewer stays physically seated throughout. “Enter the scene” is a spoken activation command. The animation alternates a viewer question and the addressed character’s response. The console waveform indicates viewer speech; a small waveform above the speaking character indicates the reply. Example dialogue is illustrative, not a live AI conversation. No walking or avatar teleportation.
