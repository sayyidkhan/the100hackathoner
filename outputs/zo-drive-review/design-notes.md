## Dark prompt

Use case stylized-concept. Landscape 3:2 premium physical miniature product sculpture for Zo Drive, a private file workspace on your own server with documents, databases, functions and controlled sharing. Compose a coherent compact personal server workbench on a thin beveled rounded rectangular ivory base, no circular pedestal. Center rear: beautiful substantial ivory server archive with dark blue recessed interior, three drawers, the middle drawer extended revealing a dozen cream file folders with red and blue tabs, brass rails and handles, subtle side ventilation. Atop archive: a large sculptural red tabbed folder holding fanned documents with fine ink lines, flanked by upright small document preview cards showing a mountain photograph relief and a spreadsheet grid. Left: a freestanding elegant brass arch sharing gateway with an ivory padlock suspended inside, red key resting at foot, flat navy pathway leading through it to a small outgoing file card. Right: a navy three-tier database cylinder with fine brass seams and status lights, beside a small angled ivory terminal with navy screen showing simple code strokes, below a brass-framed gear medallion. Foreground: small low display rack holding three distinct file cards (document, spreadsheet, presentation) connected to the central archive by thin inlaid blue routes. Use porcelain ivory, tactile paper, dark navy enamel, restrained crimson, brushed brass. Rounded edges, realistic tiny bolts, layered paper edges, precision crafted joinery and inset panels. Rich detail but readable uncluttered hierarchy, all objects physically supported. Three-quarter front view at moderate elevation, city-free, no people, no robot. Soft warm studio key light, realistic ambient occlusion and soft grounding shadows, charcoal seamless background. No typography or logos, no giant pedestal, all edges within frame with generous margins.
