# Dark-mode artwork — background edits

Method: built-in imagegen tool (image editing), 29 September 2026. Each local edit target was visually inspected first. No fallback CLI was used.

Original Museum JPGs remain unchanged for light mode. Dark PNG originals and optimized JPGs are saved beside them. These images remain conceptual project illustrations, not product screenshots or real-site photography. The edits preserve composition and object details closely, but generative editing is not pixel-exact.
