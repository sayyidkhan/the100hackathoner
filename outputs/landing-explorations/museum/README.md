# Museum of 100 Attempts

An isolated landing-page exploration for The 100 Hackathoner. Nothing in the production Astro app is changed.

## Preview

Run `npm start` here, then open http://127.0.0.1:18501. No dependencies to install. `npm run check` checks JavaScript syntax.

## Direction

A modern exhibit rather than a developer portfolio: deep green canvas, oversized condensed type, bright pink and cobalt symbolic artifacts, and a browsable collection. The opening contains no portrait and no duplicate progress grid. The immersive design skill informed the continuous green surface, hard-edged exhibit cards, tactile controls, and accessible interaction states.

The three objects are symbolic illustrations, not product screenshots. They open real project details. The collection uses a local snapshot of all 81 source records and derives the 24 award-bearing records. Search, awarded filter, load more, and surprise-me work locally. Native modal dialogs support Escape and focus management.

About, principles, judging, and contact links intentionally lead back to the existing site at port 18481. Project links lead to recorded GitHub or event URLs. Google Fonts is optional; local font fallbacks preserve the layout.
