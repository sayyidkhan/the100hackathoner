# Sculptural 100

Independent, unmerged landing-page exploration for The 100 Hackathoner.

Run `npm start` and open http://127.0.0.1:18502.
Run `npm run check` for JavaScript syntax checks.

Art direction: pale architectural canvas, dimensional cobalt typography, lime accents, and editorial scale. No portrait, no journey-map duplication. The perspective design skill informed the dimensional composition and accessible interaction states.

Native CSS artwork is conceptual; it is not represented as a product screenshot. Project content is a local snapshot of the real 81-record site data. Project buttons open keyboard-accessible native dialogs, and Discover another experiment rotates through that data. About, judging, and writing links lead to the original local site on port 18481.

No dependencies. Google Fonts is optional: system fallbacks remain usable offline. Pointer response and animation respect reduced-motion preferences. No forms, analytics, or remote data submission.

This folder is isolated from the production application. No commit, push, or merge is performed.
