# Dark technical / Concept 03

Independent landing-page exploration for The 100 Hackathoner. Nothing in the main app is changed by this prototype.

## Run

`npm start` → http://127.0.0.1:18503

`npm run check` checks JavaScript syntax. No build step or npm dependencies are required.

## Direction

A practice in possibility: near-black surfaces, violet luminosity, generous typography, and one layered abstract “100” object instead of a portrait or duplicated journey grid. The Sleek skill informed restrained hierarchy, consistent spacing, visible keyboard focus and explicit control states.

Project cards use symbolic SVG artwork, not product screenshots. All titles, dates, awards and descriptions come from a local snapshot of the site's hackathon data (81 entries / 24 award-bearing entries). The judging image is an existing site asset. The page does not claim a speaking history.

## Review

- Latest / Awarded filter updates three project selections.
- Project buttons open a native modal with real descriptions and source links.
- Escape, close button and outside click dismiss the modal; native dialog preserves keyboard focus.
- Responsive single-column layout below 780px; reduced-motion preference disables animation.
- About, full journey and essay links intentionally return to the main preview on port18481.
- Google Fonts are optional; sans-serif fallbacks work without network access.

No check-in, push or merge has been performed.
