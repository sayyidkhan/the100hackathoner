# Dark technical / Concept 03

Independent landing-page exploration for The 100 Hackathoner. Nothing in the main app is changed by this prototype.

## Run

`npm start` → http://127.0.0.1:18503

`npm run check` checks JavaScript syntax. No build step or npm dependencies are required.

## Direction

Version 2: The 100 Hackathoner / An unfinished story. Monumental brand typography leads into a native-canvas, dimensional orbital archive: 81 illuminated record slats and 19 unwritten slats. Ink-black surfaces, calibrated hairlines, restrained violet illumination and a tactile primary action take inspiration from DesignCode without copying its layouts or assets. The Sleek skill informed spacing, explicit interaction states and keyboard clarity.

Project cards use symbolic SVG artwork, not product screenshots. All titles, dates, awards and descriptions come from a local snapshot of the site's hackathon data (81 entries / 24 award-bearing entries). The judging image is an existing site asset. The page does not claim a speaking history.

## Review

- Three featured builds have unique symbolic illustrations: a drawn home, a crow above a city, and a Borneo longhouse. These are original illustrative SVGs, not product screenshots.
- Browse all 81 attempts expands a searchable archive; All / Award-bearing / 2026 filters combine with the text search. Empty searches have explicit feedback.
- Project buttons open a native modal with real descriptions and source links.
- Escape, close button and outside click dismiss the modal; native dialog preserves keyboard focus.
- Responsive single-column layout below 720px; reduced-motion preference pauses the orbital artwork by default. A visible pause/play control works independently. Animation pauses offscreen and when the tab is hidden.
- About, full journey and essay links intentionally return to the main preview on port18481.
- Google Fonts are optional; sans-serif fallbacks work without network access.

The memoir manifesto, first judging experience, eventual-book ambition, and real field-note excerpts centre the content on The 100 Hackathoner. No speaking credentials or project-specific lessons are fabricated.
